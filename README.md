# Тестирование API Яндекс Самокат

Автотесты проверяют создание курьера и ошибки при повторной регистрации или
отсутствии обязательных полей; авторизацию с корректными и некорректными
данными; создание заказов с цветами `BLACK`, `GREY`, обоими цветами или без
цвета; а также получение списка заказов. Тестовые курьеры и заказы удаляются
после проверок.

## Запуск

Установи зависимости:

```bash
python3 -m pip install -r requirements.txt
```

Запусти тесты:

```bash
python3 -m pytest
```

Базовый URL API и пути ручек находятся в `tests/constants.py`. Чтобы запустить
тесты против другого окружения, измени там `API_BASE_URL`.
